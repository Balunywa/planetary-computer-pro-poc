How StormLens is layered

A single Deploy to Azure button stands up the catalog, the secure workstation, storage, the AI models, and this web front end — all wired together with managed identity.

🗄️

GeoCatalog

Planetary Computer Pro resource — stores, indexes, and serves imagery & weather via STAC. The data plane every layer talks to.

🖥️

Analytics workstation

Windows VM (VS Code + Python + SDK), reached only over Azure Bastion. Runs the notebooks and seeds sample data with its managed identity.

📦

Storage + identity

Sample-assets and model-outputs containers; a user-assigned identity for managed-identity ingestion.

🌀

Aurora on Foundry

Azure ML / AI Foundry GPU managed-compute endpoint hosting the Aurora weather model for hurricane inference.

🤖

Azure OpenAI

Optional Foundry GPT deployment for agentic / reasoning GeoAI over the catalog, keyless via managed identity.

🌐

StormLens web app

This static site — hosted on Azure Static Web Apps, and also served locally on the workstation. Talks to the catalog with your Entra identity.

Security posture

🧩

Two hosting modes

The same static files run locally on the workstation (a quick python -m http.server) and on Azure Static Web Apps for a shareable URL.
